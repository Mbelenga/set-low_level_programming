# 0x03. Debugging

## Description

This project focuses on the concept of **debugging in C programming**. Debugging is the process of identifying, analyzing, and fixing errors (bugs) in a program to ensure it works as expected.

Throughout this project, we practice reading code carefully, identifying logical and syntax errors, and correcting them so the programs produce the correct output.

## Learning Objectives

At the end of this project, you should be able to explain:

* What debugging is
* Different methods of debugging manually
* How to read error messages and fix bugs
* How to test programs to identify problems
* How to fix logical errors in C programs

## Requirements

* Allowed editors: `vi`, `vim`, `emacs`

* All files are compiled on **Ubuntu 20.04 LTS** using:

  ```
  gcc -Wall -Werror -Wextra -pedantic -std=gnu89
  ```
