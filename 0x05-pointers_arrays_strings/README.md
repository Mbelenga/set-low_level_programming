# 0x05. C - Pointers, Arrays and Strings

## Description

This project focuses on understanding **pointers, arrays, and strings in the C programming language**. These concepts are fundamental in C because they allow direct memory access and efficient data manipulation.

Throughout this project, we practice:

* Declaring and using **pointers**
* Working with **arrays**
* Manipulating **strings**
* Understanding how pointers interact with arrays and strings

The goal is to strengthen knowledge of memory management and improve problem-solving skills using C.

---

## Learning Objectives

By the end of this project, you should be able to explain:

* What **pointers** are and how to use them
* The difference between **pointers and arrays**
* How to access and modify data using pointers
* What **strings** are in C
* How to manipulate strings using pointers and arrays
