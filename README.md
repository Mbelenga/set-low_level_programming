# Low Level Programming - C Projects

## 📌 Repository Description

This repository contains multiple projects written in the **C programming language**.

It covers basic and advanced low-level programming concepts, focusing on memory management, pointers, data structures, and system-level programming.

Each directory represents a separate project with its own tasks and README file.

---

## 🎯 Objectives

The goal of this repository is to:

* Build a strong foundation in C programming
* Understand how programs work at a low level
* Master memory management
* Practice problem-solving using C
* Follow the Betty coding style
* Compile programs using strict GCC flags

---

## 🛠 Compilation Requirements

All programs are compiled using:

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89
```

* Ubuntu 20.04 LTS
* GCC compiler
* Betty style compliant
* No memory leaks

## 💡 How to Use

Clone the repository:

```bash
git clone <https://github.com/set-low_level_programming>
cd <set-low_level_programming>
```

Navigate to any project directory and compile:

```bash
gcc file.c -o output
./output
```
