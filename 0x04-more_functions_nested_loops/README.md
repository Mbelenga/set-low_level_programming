# 0x04. More Functions, More Nested Loops

## Description
This project focuses on learning how to use more functions and nested loops in the C programming language. The tasks in this project help build a deeper understanding of loops, conditional statements, and how functions work together to perform different operations.

The goal is to practice writing clean, efficient code while solving different problems using loops and functions.

## Learning Objectives
By the end of this project, I should be able to:

- Understand how to create and use functions in C
- Use nested loops to solve programming problems
- Apply conditional statements (`if`, `else`)
- Write programs that print patterns and numbers
- Follow good coding style and documentation practices

## Project Tasks
Some of the programs in this project include:

- Checking if a character is uppercase
- Checking if a character is a digit
- Multiplying two integers
- Printing numbers and patterns
- Printing triangles and squares using loops
- Printing numbers with conditions
